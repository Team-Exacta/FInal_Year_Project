# 📊 Tourism Review Dataset

## 📌 Overview
This dataset contains tourism reviews collected from Tripadvisor. Each record represents a single user review for a tourist destination (e.g., Angurukaramulla Temple, Negombo, Sri Lanka).  
It includes multiple places and multiple reviews per place.

---

## 📁 Dataset Structure
- Each row = one review  
- Multiple reviews per place  
- Multiple places included  
- Available in CSV and JSON formats  

---

## 🧾 Fields Description
- `place_name` – Name of the tourist place  
- `rating` – Rating given by the user (1–5)  
- `title` – Short title of the review  
- `body` – Detailed review text  
- `date` – Date of the review  
- `reviewer` – Name of the reviewer  
- `reviewer_location` – Reviewer’s location  
- `type_of_traveler` – Type of traveler (e.g., family, solo)  
- `contributions` – Number of reviews by the user  
- `page_url` – Link to the original review  

---

## 🎯 Use Cases
- Recommendation systems  
- Sentiment analysis  
- User behavior analysis  
- Tourism insights
