About this project

Why use this recommendation system

A final-year research project that turns unstructured traveller reviews into planning decisions you can check for yourself.

Grounded in real reviews

Nothing is invented. Every timing, crowd and cost verdict traces back to review sentences you can read, each with a confidence score.

Match scores you can question

Recommendations are ranked by rating, evidence volume and how well a place fits the filters you set — not by who paid to be listed.

Routes built on real roads

The planner balances attraction value, budget, driving time and popularity, then splits the winning route into practical days.

Under the hood

How the three modules fit together

Each part of the project feeds the next.

Module 01

UGC analysis

Review sentences are classified and normalised into structured facts — best time, crowd level, cost band — each with a confidence score and the source sentences behind it.

Module 02

Knowledge graph + RAG

Those facts join Wikipedia articles and extracted features in a Neo4j graph and vector store, queried by an intent-routed LangGraph agent.

Module 03

Itinerary optimisation

A multi-objective ant-colony search explores the POI graph under time budgets, returning Pareto-ranked routes split into daily plans.
